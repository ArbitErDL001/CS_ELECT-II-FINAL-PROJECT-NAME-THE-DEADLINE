# CS_ELECT-II-FINAL-PROJECT-NAME-THE-DEADLINE

# GAME NAME: The Deadline


# Overview
The Deadline is a survival horror game set in a mysterious office lobby. Players must collect scattered project files before the looming Deadman catches them. If the Deadman captures you, the ultimate horror unfolds — the deadline is due.

# Gameplay
Objective: Collect all project files hidden throughout the lobby.

Threat: Avoid the Deadman, a relentless figure that stalks the halls.

Challenge: Time pressure and eerie atmosphere make every step tense.

Victory: Deliver all projects before being caught.

Failure: If the Deadman captures you, the deadline is instantly due — game over.

# Controls
Movement: WASD / Arrow keys

Collect: Press left mouse button near a project file

Sprint: Hold Shift to escape danger

Flashlight: Press F key
